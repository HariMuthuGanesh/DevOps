# Backend API Development

This directory contains the REST API backend service for the DevOps Model Lab environment.

## Features
- **Express.js API Server**: Health checks and REST endpoints.
- **Environment Management**: Configured with `.env` for database connection (`MONGO_URI`).
- **DevOps Integration**: Can be integrated into Jenkins multi-stage build pipelines.

## Running Locally
```bash
npm install
npm start
```
